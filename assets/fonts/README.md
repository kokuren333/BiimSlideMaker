# Bundled fonts

- `NotoSansJP-Variable.ttf`: Noto Sans JP; SIL Open Font License in `OFL.txt`.
- `MPLUSRounded1c-ExtraBold.ttf`: Rounded M+ / M PLUS Rounded 1c ExtraBold, unmodified font distributed by Google Fonts. Copyright 2016 The Rounded M+ Project Authors. SIL Open Font License in `MPLUSRounded1c-OFL.txt`.

Rounded font source: https://github.com/google/fonts/tree/main/ofl/roundedmplus1c

Keep the corresponding copyright and OFL text when copying either font. The renderer registers the rounded font under the CSS family name `M PLUS Rounded 1c`; the binary's legacy family name is `Rounded Mplus 1c ExtraBold`. No system installation or remote font service is needed.
